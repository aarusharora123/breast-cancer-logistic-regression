# Breast Cancer Classification Using Logistic Regression

This project uses logistic regression to classify breast tumors as malignant or benign from numerical nuclear-morphology measurements in the Wisconsin Diagnostic Breast Cancer dataset.

The notebook covers data inspection, exploratory analysis, feature relationships, preprocessing, model fitting, and classification evaluation. It is an educational analysis and is not intended for clinical diagnosis or decision-making.

## Notebook

Open `breast_cancer_logistic_regression.ipynb` to review the complete analysis and executed outputs.

## Dataset

Wisconsin Diagnostic Breast Cancer dataset:
https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
